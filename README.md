# موقع الملفات القانونية

الموقع: https://razanabdulaziz92-source.github.io/legal-files

## الإدارة
افتحي https://razanabdulaziz92-source.github.io/legal-files/admin.html (أو رابط «الإدارة» أسفل الموقع).
منها تقدرين:
- ترفعين ملفات PDF جديدة وتختارين قسمها.
- تعدلين اسم أي ملف أو تنقلينه لقسم ثاني، أو تحذفينه.
- تضيفين أقسام، وتغيرين أسماءها وأيقوناتها وترتيبها.

الدخول يكون بمفتاح (Fine-grained token) من GitHub بصلاحية Contents: Read and write على المستودع legal-files فقط، والخطوات مكتوبة في صفحة الدخول.
بعد الحفظ تظهر التغييرات في الموقع خلال دقيقة أو دقيقتين.

## محتويات المشروع
- `index.html` صفحة الموقع.
- `admin.html` لوحة الإدارة.
- `data/library.json` فهرس الملفات (الاسم، القسم، الرابط).
- `sections.json` ترتيب الأقسام وأيقوناتها.
- `uploads/` الملفات المرفوعة من لوحة الإدارة.
- بقية الملفات محفوظة في المستودعات legal-lib-1 إلى legal-lib-6.
- `lib/` عارض PDF (PDF.js).
