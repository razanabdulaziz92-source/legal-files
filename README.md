# موقع الملفات القانونية

موقع بسيط مفتوح للجميع: قائمة ملفات PDF، بحث بالاسم، عرض الملف داخل المتصفح، وزر تحميل.

## إضافة ملف جديد
1. افتحي المستودع على GitHub ثم مجلد `files`، ثم مجلد القسم المناسب (مثل «العقود والنماذج»).
2. اضغطي **Add file ← Upload files** وارفعي ملف (أو ملفات) PDF.
3. اضغطي **Commit changes**.

بعد دقيقة إلى دقيقتين يظهر الملف في الموقع تلقائيًا. اسم الملف هو الاسم الذي يظهر للزوار
(الشرطة `-` والشرطة السفلية `_` تتحول إلى مسافة).

## الأقسام
كل مجلد داخل `files` يظهر كقسم في الموقع. لإضافة قسم جديد ارفعي الملفات داخل مجلد جديد باسم القسم.
ترتيب الأقسام ووصفها وأيقوناتها في ملف `sections.json`.

## حذف ملف
افتحي الملف داخل مجلد `files` ← زر النقاط الثلاث ← **Delete file** ← **Commit changes**.

## محتويات المشروع
- `index.html` صفحة الموقع، وتقرأ قائمة الملفات من مجلد `files` تلقائيًا.
- `files/` ملفات PDF.
- `lib/` عارض PDF (PDF.js) محفوظ داخل الموقع نفسه.
