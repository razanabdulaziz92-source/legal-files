الدخول

الدخول يكون بـ«مفتاح دخول» من حسابك في GitHub. تسوينه مرة وحدة بس، وبعدها يتذكرك المتصفح.

  1. افتحي صفحة إنشاء المفتاح في GitHub (لازم تكونين مسجلة دخول).
  2. في Token name اكتبي أي اسم، مثل: لوحة المكتبة. وفي Expiration اختاري المدة اللي تبينها.
  3. في Repository access اختاري Only select repositories ثم اختاري legal-files.
  4. في Permissions افتحي Repository permissions، وخلي Contents على Read and write.
  5. اضغطي Generate token، وانسخي المفتاح والصقيه هنا.

المفتاح يُحفظ في متصفحك فقط، ولا يُرسل لأي مكان غير GitHub. لا تشاركينه مع أحد.
